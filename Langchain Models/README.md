# LangChain Models Learning Journey

This repository documents my journey of learning LangChain. It includes code examples and projects for various LangChain modules.

## Folders

*   **1.LLMs**: Demonstrations of Large Language Models.
*   **2.ChatModels**: Examples of using different chat models (OpenAI, Anthropic, Gemini, Hugging Face).
*   **3.EmbeddedModels**: Code for using embedding models.

## Usage

Each folder contains Python scripts that can be run independently. Make sure to install the required dependencies from `requirements.txt`.

```bash
pip install -r requirements.txt
```
